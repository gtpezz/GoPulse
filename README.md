**GoPulse** — это легковесная кроссплатформенная десктопная утилита для мониторинга ресурсов операционной системы и управления процессами в реальном времени. Приложение представляет собой эффективную альтернативу стандартным системным диспетчерам задач с возможностью накопления и анализа исторической статистики нагрузки.

---

## ✨ Возможности

📊 **Дашборд реального времени**
* Обновление метрик строго 1 раз в секунду.
* Интерактивные live-графики (CPU, RAM) без рывков с плавной анимацией.
* Детальный мониторинг дисковой активности (свободно/всего, скорость чтения/записи) и сети (скачивание/отдача).

⚙️ **Диспетчер процессов**
* Полный интерактивный список запущенных в операционной системе процессов.
* Быстрый поиск и фильтрация по имени, а также эффективная сортировка по PID, CPU и памяти.
* Принудительное завершение процессов (Kill) прямо из интерфейса с обработкой системных ошибок доступа.

📈 **История и аналитика**
* Умное сохранение данных: секундные метрики агрегируются в памяти, и в базу данных записывается только среднее значение за минуту.
* Просмотр ретроспективной аналитики за различные периоды (1 час, 24 часа, 1 неделя) на статических графиках трендов.

🎨 **Системная интеграция и UX**
* Сворачивание в системный трей (Tray Icon) при нажатии кнопки закрытия окна `[X]`.
* Поддержка темного и светлого режимов оформления (Dark / Light Mode).

## 🛠 Технологический стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Бэкенд** | `Go 1.21+` | Основная логика, конкурентность, работа с ОС |
| **Десктоп-среда** | `Wails v3` | Кроссплатформенный фреймворк для связи Go и UI |
| **Метрики** | `gopsutil/v4` | Кроссплатформенный сбор низкоуровневых данных ОС |
| **База данных** | `SQLite` (драйвер `modernc.org/sqlite`) | Встраиваемая БД на Pure Go (не требует CGO) |
| **Фронтенд** | `React` + `JavaScript` | Интерфейс пользователя |
| **Стилизация** | `TailwindCSS` | Адаптивная верстка и темы оформления |
| **Графики** | `Chart.js` (или `ApexCharts`) | Визуализация live-метрик и истории |

## 🚀 Установка и запуск

### Предварительные требования
1. Установленный [Go 1.21+](https://go.devdoc/install).
2. Установленный [Node.js](https://nodejs.org) и менеджер пакетов npm (для сборки фронтенда).
3. Установленный CLI-инструмент [Wails v3](https://wails.io).

### Клонирование репозитория
```bash
git clone https://github.com
cd gopulse
```

### Запуск в режиме разработки (Dev)
Команда запускает приложение в режиме live-reload для бэкенда и фронтенда:
```bash
wails dev
```

### Компиляция и сборка (Production)

Приложение собирается в единый оптимизированный бинарный файл.

#### Сборка под Windows:
```bash
wails build -platform windows/amd64
```

#### Сборка под Linux (Ubuntu/Debian):
```bash
wails build -platform linux/amd64
```

## 🗄 Схема базы данных

Локальная база данных `gopulse.db` инициализируется автоматически при первом запуске утилиты в папке приложения или системной директории AppData.

```sql
CREATE TABLE IF NOT EXISTS system_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    cpu_usage_avg REAL,         -- Средний % загрузки CPU за минуту
    ram_usage_avg REAL,         -- Средний % использования RAM за минуту
    net_download_bytes INTEGER, -- Суммарный входящий трафик за минуту
    net_upload_bytes INTEGER    -- Суммарный исходящий трафик за минуту
);
```

## 📋 Нефункциональные требования

* **Низкое потребление ресурсов:** GoPulse не нагружает процессор более чем на 1-2% в режиме активного мониторинга. Ограничение по потреблению оперативной памяти составляет до 50-70 МБ RAM без утечек.
* **Нативная кроссплатформенность:** Код компилируется под Windows 10/11 и Linux. Ограничения специфичных системных вызовов изолированы с помощью механизмов `runtime.GOOS` или build tags.
* **Плавность UI:** Отсутствие рывков и задержек при отрисовке live-графиков (реализована плавная анимация сдвига точек влево).
